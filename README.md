## 🤖 Featured Projects

### 🦾 ORION — Autonomous Robotics Platform

A Raspberry Pi-based autonomous robotics project combining:

* Computer vision & object detection
* Sensor fusion
* Decision making
* PPO-based control
* Embedded C++ hardware drivers
* Python AI/execution layer
* Safety layer & motor control
* `pybind11` integration between C++ and Python

**Goal:** build a robot capable of following a human while making autonomous movement decisions.

---

### 🔤 OCRfromScratch

A from-scratch OCR project focused on understanding **computer vision and image processing at a lower level** rather than treating ML libraries as black boxes.

The project explores:

* Image representation
* Image processing fundamentals
* C++ implementations
* Python bindings through `pybind11`
* Neural network-based recognition
* The mathematics behind the pipeline

> **Goal:** understand what actually happens between pixels and predictions.
